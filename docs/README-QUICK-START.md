# Quick Start for Reviewers

1. Read the project disclaimer and scenario in the top-level `README.md`.
2. Review the five policies in order from `policies/`.
3. Inspect `docs/control-mapping.csv` for the intent and limits of the framework mapping.
4. Review `docs/risk-register.csv` and note that target residual scores are not measured.
5. Use `docs/evidence-register.csv` and `docs/audit-test-plan.md` to understand how the controls could be evidenced and tested.
6. Read `docs/project-notes-and-assumptions.md` before reusing any text outside this fictional scenario.

Recommended first extension: add a Secure SDLC / Change Management Standard and a Backup & Recovery Standard, then update the risk register and test plan to cover CI/CD changes and restoration testing.
